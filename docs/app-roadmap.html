What exists today

Code presence, not a production certification.

Archive pipeline

ZIP uses unzipper and other recognized archives use bundled 7zip. Extraction validates paths, counts and disk budgets, but currently extracts every ZIP entry and rejects encrypted archives.

server/application/jobs/extractSessionSource.ts

HTTP and torrent downloads

HTTP supports segmented transfer and retry/resume. Selective torrents have retained SQLite state; HTTP libraries still need a durable lifecycle.

Which download links can we grab?

Feasibility, not universal support.

Direct and linked files

Normal redirects, HTML links and supported landing pages are practical first steps. Review candidates, then use the existing guarded downloader. Bound every crawl by origin, depth, pages, bytes and time.

L01–L04 · D01–D03

Signed URLs and cookies

Playwright observes downloads and shares a browser-context cookie jar. A separate browser-assisted resolver is feasible. Some requests also need a method, body, CSRF token or live session. Start with controlled fixtures and supported sites.

L05–L06 · D05

The user's browser is separate

A remotely hosted Express server cannot read cookies from an existing personal browser. Offer explicit login in an isolated resolver or an opt-in local extension/helper. Do not scrape browser profiles or export all cookies.

Private per-user, per-origin sessions

Some downloads stay manual

DRM, CAPTCHA, device-bound sessions, one-time responses and access restrictions prevent universal support. Explain unsupported cases and retain manual import. A browser-only blob URL is not a reusable server link.

A07 · L05

Media behavior

Video supports original, remux and adaptive playback. Long-video seeks prepare the requested window; cached storyboards preview the target while dragging.

Read media playback for user controls and testing and benchmarks for verification commands. Player cleanup and preparation proposals are N06 and P01-P02.
