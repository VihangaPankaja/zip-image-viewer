# Settings

Open the settings button in the workspace header. Changes save automatically;
save failures appear beside the affected control.

## Browser preferences

- Choose System, Light or Dark appearance. System follows the device theme.
- Choose file sorting, preview quality and visible file columns.
- Set the video seek interval and playback-speed step for keyboard shortcuts.

These choices apply to this browser. Video quality beside the player controls
the current video; it is separate from the default preview setting.

## Shared download controls

Concurrent downloads and torrent bandwidth limits affect the server, including
other open browsers. HTTP thread count, multithreaded transfer, resume and retry
settings apply to HTTP downloads. Torrent file priority lives in **View files**.

See [downloads](downloads.md) for queue actions and [playback](playback.md) for
media controls. Server environment options are in
[configuration](../reference/configuration.md).
